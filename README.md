# ItzFizz – Scroll-Driven Hero Animation

## Overview
ItzFizz is a modern, visually engaging web experience featuring a premium hero section with smooth entrance animations and scroll-based visual interactions. The design focuses on fluid motion, and clean typography.

LIVE LINK: https://itzfizz-eta.vercel.app/
## Features

### 1. Hero Section Layout
- Full-screen hero section visible above the fold.
- Letter-spaced headline: **W E L C O M E I T Z F I Z Z**
- Impact metrics and statistics displayed below the headline.
- Clean, modern, and responsive layout.

### 2. Initial Load Animations
- Smooth fade-in and subtle movement for the main headline.
- Staggered reveal animations for statistics and metrics.
- Carefully timed transitions for a polished first impression.

### 3. Scroll-Based Animations
- The hero section responds dynamically to page scrolling.
- The main visual element moves smoothly according to scroll progress.
- Interpolated motion creates a natural and fluid animation experience.
- Animations are controlled by scroll position rather than time-based autoplay.

### 4. Performance and Motion
- Uses transform-based animations wherever possible.
- Minimizes unnecessary layout recalculations during scrolling.
- Prioritizes smooth transitions and responsive interactions.
- Designed to provide a consistent experience across screen sizes.

## Tech Stack
- React.js
- Vite
- JavaScript
- CSS
- Tailwind
- GSAP (GreenSock Animation Platform)


## Deployment
The project can be deployed on Vercel.

- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`

## Project Goals
- Create an engaging first-screen experience.
- Deliver smooth, scroll-synchronized visual movement.
- Combine typography, statistics, and motion into a cohesive design.
